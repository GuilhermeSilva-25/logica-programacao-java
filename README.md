# 🐝 Beecrowd - Soluções em Java
![Java](https://img.shields.io/badge/Java-007396?style=for-the-badge&logo=java&logoColor=white)

Este repositório contém as minhas soluções para os exercícios de lógica de programação da plataforma [Beecrowd](https://www.beecrowd.com.br/) (antigo URI Online Judge), desenvolvidas em **Java**.

## 📌 Sobre o Projeto

O objetivo principal deste repositório é servir como portfólio e área de estudos de algoritmos, estruturas de dados e lógica de programação. 

Uma particularidade deste repositório é a divisão de abordagens. Além das resoluções tradicionais e diretas, o projeto inclui versões alternativas explorando a **Programação Orientada a Objetos (POO)**.

## 📂 Estrutura do Repositório

As soluções estão organizadas em pastas baseadas nas abordagens:

- 📁 **`Iniciante/`**
  Soluções focadas em resolver o problema de forma mais procedural, estruturada e direta, ideal para focar na lógica algorítmica.

- 📁 **`Iniciante(POO)/`**
  Os mesmos problemas resolvidos aplicando conceitos rígidos de Programação Orientada a Objetos (interfaces, injeção de dependências, separação de responsabilidades). Excelente para o estudo de padrões de projeto e arquitetura, utilizando exercícios simples para aplicar conceitos complexos de engenharia de software.

> ⚠️ **Aviso Importante sobre o Beecrowd:** 
> Para organizar o repositório, os arquivos estão nomeados como `MainXXXX.java` (onde `XXXX` é o número do problema no Beecrowd). Porém, a plataforma exige que a classe principal seja nomeada obrigatoriamente como `Main` e que o código não possua pacote (`default package`). Lembre-se de renomear a classe e o arquivo antes de submeter!

## 🚀 Como Executar Localmente

### Pré-requisitos
- [Java JDK](https://www.oracle.com/java/technologies/downloads/) (versão 11 ou superior recomendada).

### Passo a passo

1. Abra o terminal e acesse a pasta da categoria desejada:
```bash
cd Iniciante
```

2. Compile o arquivo `.java` (substitua `1000` pelo número do exercício):
```bash
javac Main1000.java
```

3. Execute a classe `.class` gerada:
```bash
java Main1000
```
