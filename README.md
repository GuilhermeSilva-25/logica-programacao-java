# Beecrowd - Soluções em Java

Este repositório contém as minhas soluções para os exercícios de lógica de programação do plataforma [Beecrowd](https://www.beecrowd.com.br/) desenvolvidas em **Java**.

## 📌 Sobre

O objetivo principal deste repositório é servir como portfólio e área de estudos de algoritmos, estruturas de dados e lógica de programação utilizando a linguagem Java.

## 🚀 Como Executar

O Beecrowd (antigo URI Online Judge) exige que, para a linguagem Java, a classe que contém o método `main` seja nomeada obrigatoriamente como `Main` (sem pacote / `default package` ao enviar para a plataforma).

Para compilar e executar os exercícios localmente através do terminal:

1. Compile o arquivo `.java`:
```bash
javac Main.java
```

2. Execute o arquivo `.class` gerado:
```bash
java Main
```
